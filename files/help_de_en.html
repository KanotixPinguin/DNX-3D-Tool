DNX 3D Tool – Hilfe (Deutsch)

Bedienung

  • Linke Maustaste + ziehen: Drehen (Yaw/Pitch)
  • Rechte Maustaste + ziehen: Vertikal verschieben
  • Mausrad: Zoom/Peakhöhe (je nach Modus)
  • Rechte Maustaste + Mausrad: Kamera rein/raus
  • Fensterrahmen/Ecken: Größe ändern (alle 4 Kanten + 4 Ecken)

Regler/Funktionen

  • FFT Window / FFT Size / Overlap: Spektrum-Charakteristik
  • AVG / Samples: Glättung über Zeit
  • Ref dB / Range dB: Pegel- und Dynamikdarstellung
  • Palette: Farbschema (Default/Turbo/Legacy/...)
  • 3D Mode: Points / Lines / Solid / Shaded / Outline
  • AutoScale: Rücksetzung auf Standarddarstellung
  • Smooth / Sharp / Bright (+/-): Feintuning der Oberfläche

DNX 3D Tool – Help (English)

Controls

  • Left mouse + drag: Rotate (Yaw/Pitch)
  • Right mouse + drag: Vertical shift
  • Mouse wheel: Zoom/peak-height (mode dependent)
  • Right mouse + wheel: Camera in/out
  • Window frame/corners: Resize (all 4 edges + 4 corners)

Parameters

  • FFT Window / FFT Size / Overlap: Spectrum behavior
  • AVG / Samples: Time smoothing
  • Ref dB / Range dB: Level and dynamic range mapping
  • Palette: Color scheme (Default/Turbo/Legacy/...)
  • 3D Mode: Points / Lines / Solid / Shaded / Outline
  • AutoScale: Reset to default view
  • Smooth / Sharp / Bright (+/-): Surface fine tuning

Tip: If the source canvas is temporarily unavailable, wait a moment and reopen the tool.
